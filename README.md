# BetterNPCBoats

Adds a new NPC fishing boat and adds them around ports.

### Installation

If updating, remove BetterNPCBoats folders and/or BetterNPCBoats.dll files from previous installations.  
<br>
Extract the downloaded zip. Inside the extracted BetterNPCBoats-\<version\> folder copy the BetterNPCBoats folder and paste it into the Sailwind/BepInEx/Plugins folder.
